# 03 环境搭建与第一个可玩场景

> 目标：**今天之内**装好 Unity、建好工程、把代码导进去、跑起来一个「敌人沿路径走」的场景。
> 不要一上来就搭 UI，先把「能看到东西动」的成就感拿到。

---

## 1. 装 Unity（约 40 分钟，主要等下载）

1. 打开 <https://unity.com/download> 下载 **Unity Hub**，装完登录/注册 Unity ID。
2. Hub 左侧 `Installs` → `Install Editor` → 选 **Unity 6 LTS**（版本号是 `6000.x`，选标着 LTS 的最新一个）。
   - 如果学校电脑配置老，选 **2022.3 LTS** 也可以，本套代码两个版本都能跑。
3. 勾选模块（重要）：
   - ✅ **Windows Build Support (IL2CPP)** —— 打包 exe 用，比赛要交可运行程序
   - ✅ **Visual Studio Community**（或你已有 VS Code / Rider 可跳过）
   - ❌ 其他平台（Android/iOS/WebGL）先不装，省 10G 空间
4. 等待安装完成。

> 磁盘：Unity 编辑器 + 一个工程大约 10~15 GB，留 30 GB 余量。

---

## 2. 建工程

1. Hub → `Projects` → `New project`
2. 模板选 **Universal 2D**（有的版本叫 `2D (URP)`）。
   ⚠️ **不要选 `2D (Built-in Render Pipeline)`**，赛题要求 URP。
3. 工程名：`TowerDefense`；路径：**不要放在中文路径下**（例如 `D:\Unity\TowerDefense`），
   中文路径 + 空格是 Unity 各种诡异报错的常见来源。
4. `Create project`，第一次打开会编译几分钟。

### 首次进入后立刻做 4 件事

| 操作 | 路径 | 为什么 |
|---|---|---|
| 导入 TMP 资源 | `Window > TextMeshPro > Import TMP Essential Resources` | 不导入，所有文字都是空白/报错 |
| 打开旧输入 | `Edit > Project Settings > Player > Other Settings > Active Input Handling` 选 **Both** | 本套代码用 `Input.GetMouseButtonDown`，不设 Both 会抛异常 |
| 确认渲染管线 | `Project Settings > Graphics` 里 `Default Render Pipeline` 有值；`Project Settings > Quality` 里也是 | 空的话说明模板没配好 URP |
| 设分辨率 | `Project Settings > Player > Resolution` 设 1920×1080，`Fullscreen Mode` 用 Windowed 方便调试 | 免得 UI 在编辑器里被拉伸得看不出问题 |

## 3. 建目录结构

在 `Assets` 下建这些文件夹（名字随意，但这套文档会按它写）：

```
Assets/
├── _Project/              ← 自己的东西都放这，和插件资源分开
│   ├── Art/               Sprite、材质
│   ├── Audio/             音乐、音效
│   ├── Data/              TowerData / EnemyData / LevelWaves 资产
│   ├── Prefabs/           敌人、子弹、塔、地块
│   ├── Scenes/            MainMenu、Level_01/02/03
│   └── Scripts/           ← 把本套 Assets/Scripts 整个文件夹拖进来
└── TextMesh Pro/
```

把 `TowerDefenseKit/Assets/Scripts` **整个文件夹**拖到 `Assets/_Project/Scripts` 下。
回到 Unity，等编译条转完，Console 应该**没有红色报错**。
> 如果报错 `The type or namespace name 'TMPro' could not be found`：
> 说明 TMP 没导入，回上一节做第 1 条。

## 4. URP 2D 的「灯」怎么开

这是 2D 项目最容易懵的地方：**URP 2D 下 Sprite 默认可能不受光，加了灯反而全黑。**

1. 场景里 `Hierarchy` 右键 → `Light > Global Light 2D`，`Intensity` 设 1。
   → 这一步是「让画面亮起来」的兜底，**没有它可能全黑**。
2. 在美术资源上，把 Sprite 的 `Material` 设成 `Sprite-Lit-Default`（默认就是这个，别改成 Unlit）。
3. 想加氛围：再加几个 `Point Light 2D`（不用挂脚本），放在塔基座、熔岩、路口。
4. 每个关卡场景都别忘了加 `Global Light 2D`（新场景是空的）。

检查方法：把 `Global Light 2D` 的 `Intensity` 拉到 0，画面应该变暗；拉回 1 恢复。
如果拉了没变化，说明 Sprite 用的是 Unlit 材质。

## 5. 相机怎么设

选中 `Main Camera`：

| 属性 | 值 | 说明 |
|---|---|---|
| Projection | Orthographic | 2D 必须 |
| Size | 5 ~ 6 | 视野高度的一半（世界单位）。地图 20×12 的话，Size≈6 |
| Background | 深色（如 `#1B2233`） | 别用纯黑，地图边界会看不清 |
| Position Z | -10 | 2D 相机固定在 z=-10 |
| Clear Flags | Solid Color | |

**约定：1 个世界单位 = 1 个格子**。所有 Sprite 的 `Pixels Per Unit` 保持一致（默认 100），
这样贴图大小和世界坐标才对得上。

## 6. 第一个场景：让敌人沿路径走（30 分钟）

不写一行新代码，全部用现成脚本：

1. `File > New Scene` → 保存为 `Assets/_Project/Scenes/Dev_Test.unity`（临时测试场景，别用 Level 命名）
2. Hierarchy 建：
   ```
   Main Camera
   Global Light 2D
   PoolManager            (空物体 + PoolManager 脚本)
   GameManager            (空物体 + GameManager 脚本)
   Path (WaypointPath)    (空物体 + WaypointPath 脚本)
     ├─ P0  (空物体，位置 -8, 0)
     ├─ P1  (空物体，位置 -4, 3)
     ├─ P2  (空物体，位置  0, 0)
     ├─ P3  (空物体，位置  4, -3)
     └─ P4  (空物体，位置  8, 0)
   ```
3. 选中 `Path`，把 `P0~P4` 按顺序拖进 `WaypointPath` 的 `points` 数组。
   → Scene 视图里应该出现橙色连线（Gizmos 打开的情况下）。
4. 建敌人预制体（见下），拖到场景里，手动给它挂 `Enemy` + `EnemyHealth`。
5. 建一个临时脚本 `DevSpawner.cs`：

```csharp
using UnityEngine;

public class DevSpawner : MonoBehaviour
{
    public EnemyData data;
    public WaypointPath path;
    public Enemy enemyPrefab;   // 场景里那个敌人

    private void Start()
    {
        enemyPrefab.Setup(data, path.GetPoints(), enemyPrefab.GetComponent<EnemyHealth>());
    }
}
```

6. Play。敌人应该从 P0 一路走到 P4，然后扣 1 点生命（Console 无报错）。

**这一步跑通，说明路径、数据、生命值三条链路都对了。** 后面所有东西都是往上加。

> 如果不走：先看 `Enemy.Setup` 有没有被调用、`path.GetPoints()` 是不是空、
> `GameManager.Instance` 在不在（见 06 文档的排查表）。

## 7. Git 与 GitHub（第一天就做，别拖）

比赛要求「全程提交至 GitHub」，**commit 时间线本身就是证据**。

```powershell
cd D:\Unity\TowerDefense
git init
git lfs install                 # 大文件（psd/音频）建议走 LFS，可选
# 把 TowerDefenseKit 根目录的 .gitignore 复制到工程根目录
git add .
git commit -m "chore: 初始化 Unity 工程与基础脚本"
```

在 GitHub 新建**公开**仓库 `tower-defense-hl2026`，然后：

```powershell
git remote add origin https://github.com/<你的用户名>/tower-defense-hl2026.git
git branch -M main
git push -u origin main
```

之后每天至少一次：

```powershell
git add .
git commit -m "feat: 三种防御塔与升级逻辑"
git push
```

### commit message 建议格式

| 前缀 | 用途 | 例子 |
|---|---|---|
| `feat:` | 新功能 | `feat: 加入范围伤害炮塔与爆炸粒子` |
| `fix:` | 修 bug | `fix: 暂停时飘字提示不消失` |
| `refactor:` | 重构 | `refactor: 敌人血量拆出 EnemyHealth` |
| `chore:` | 杂项 | `chore: 补充音效素材与来源说明` |
| `docs:` | 文档 | `docs: 更新关卡数值表` |

> 一天一个巨型 commit 也比你想象的糟：评委看到「一次性上传 300 个文件」，
> 很难相信是你自己从零写的。宁可一天 3 个小 commit。

## 8. 编辑器速览（不熟就先记这 8 个）

| 操作 | 快捷键 |
|---|---|
| 移动 / 旋转 / 缩放 工具 | `W` / `E` / `R` |
| 2D 视角 / 3D 视角切换 | `2D` 按钮（Scene 窗口左上） |
| 聚焦选中物体 | `F` |
| 拖拽时吸附到网格 | 按住 `Ctrl` |
| 复制物体 | `Ctrl + D` |
| 保存场景 | `Ctrl + S` |
| 运行 / 停止 | `Ctrl + P` |
| 打开 Console | `Ctrl + Shift + C` |

**Play 模式下的修改会全部丢失**——想保留就先停止再改。
（有个例外：Inspector 里改的数值在 Play 时调完，可以右键组件 → `Copy Component`，停下来再 `Paste Component Values`。）
