# 05 六周开发路线

> 假设你每周能投入 **12~15 小时**（工作日晚 1.5 小时 + 周末各 4~5 小时）。
> 如果时间更少，看文末「压缩版」；如果时间更多，看「增强版」。
> **原则：每周结束时必须有一个「能 Play 给室友看」的东西。**

---

## 总览

| 周 | 主题 | 周末的产出 | 对应赛题条目 |
|---|---|---|---|
| 0（3 天） | 装环境 + C# 扫盲 | 敌人能沿路径走 | — |
| 1 | 战斗核心：塔 + 敌人 + 建造 | 能建塔打死怪、能升级 | 建造升级、防御设施、敌人 |
| 2 | 循环闭合：波次 + 经济 + 胜负 + HUD | 一关能被打通/打输 | UI、敌人（5 波） |
| 3 | 内容量：3 关 + 3 塔 + 4 敌人 | 三关可玩，难度递增 | 游戏场景（3 个） |
| 4 | 表现力：音效 + 灯光 + 粒子 + 引导 | 看起来像个「成品」 | 音效、灯光、新手引导 |
| 5 | 打磨：对象池验证 + Bug + 平衡 + 打包 | 无报错可通关的 exe + 视频 | 全部验收 |
| 6 | 缓冲 + 答辩准备 | GitHub 时间线完整 | 提交 |

> 留第 6 周是**故意的**。Unity 项目的 bug 通常集中出现在第 5 周之后才发现的交互问题，
> 没有缓冲周 = 最后一天通宵且大概率交半成品。

## 第 0 周（3 天）：装环境 + 让敌人走起来

| 天 | 任务 | 完成标志 |
|---|---|---|
| D1 | 读 `01` `02`，装 Unity、建工程、导入脚本、配 URP 灯 | Console 无红字 |
| D2 | 读 `03`，搭测试场景，敌人沿 `WaypointPath` 走完 | 生命值 -1 |
| D3 | 读 `04` 的 A、B 节，建完 4 个敌人数据 + 3 个塔数据 + 3 个子弹预制体 | 数据资产齐了 |

**这一周不要碰 UI。** 新手最常见的失败是「先花一周搭 UI，结果核心逻辑没跑通，UI 白搭」。

## 第 1 周：战斗核心（最爽的一周）

| 天 | 任务 |
|---|---|
| D1 | 敌人预制体补完（Body + 血条），`WaveManager` 单波生成测试 |
| D2 | 塔预制体 + `Projectile` 打通：建一座箭塔能打死步兵 |
| D3 | `BuildTile` + `BuildManager`：能点地块建塔、扣钱 |
| D4 | 三种塔的差异：炮塔范围伤害、冰塔减速（**减速时敌人变蓝白，肉眼确认**） |
| D5 | `TowerInfoPanel`：选中塔、升级、出售 |
| 周末 | 自己搭一张地图，用 3 种塔打死 20 只怪；把这周代码 commit 并 push |

**本周末验收**：不靠 UI 也能（在 Inspector 里手动生成）打完一波，三种塔效果肉眼可区分。

## 第 2 周：把循环闭合

| 天 | 任务 |
|---|---|
| D1 | `LevelWaves` 配 5 波，`WaveManager` 的布防倒计时跑通 |
| D2 | HUD：金币、生命、波次、倒计时（订阅事件，不轮询） |
| D3 | `ResultPanel`：胜利/失败面板 + 重开 |
| D4 | `PauseMenu`：Esc 暂停 + 继续/重开/设置/主菜单（四个都要） |
| D5 | `SceneFader`：主菜单 → 关卡 → 回主菜单，淡入淡出 |
| 周末 | **第一次完整通关**：从主菜单进第一关，打到第 5 波胜利，回主菜单 |

**本周末验收**：这就是「最小可交付版本」。哪怕美术全是色块，赛题基础项已经完成 70%。

## 第 3 周：内容量

| 天 | 任务 |
|---|---|
| D1 | 复制 `Level_01` 做 `Level_02`：换地图布局（路更长、拐更多） |
| D2 | `Waves_Level02` 调数值（数量 ×1.3，重甲提前出现） |
| D3 | 复制做 `Level_03`：熔岩主题 + 更难的波次 |
| D4 | `LevelSelectPanel` + `SaveSystem`：通关解锁下一关 |
| D5 | 平衡：自己用「常规打法」打三关，记录剩余生命 |
| 周末 | 三关都能通关，难度递增明显 |

**平衡的目标**：第一关剩 5~8 血（教学），第二关剩 2~4 血，第三关剩 1~2 血。
如果第三关打不过，先别降难度——**先想想是不是玩家有更优解**（比如冰塔放拐角）。这才是塔防的乐趣。

## 第 4 周：表现力（评委的「第一印象」全在这周）

| 天 | 任务 |
|---|---|
| D1 | 找齐素材：3 个塔、4 个敌人、地块、背景、UI 图标、BGM×2、音效×6（记录来源！） |
| D2 | 替换所有色块美术，调 Sorting Order，检查遮挡关系 |
| D3 | 音效接入（建造/开火/死亡/到达/胜负），加音量设置 |
| D4 | URP 灯光：每关加 `Global Light 2D` + 2~3 个 `Point Light 2D` 做氛围 |
| D5 | 粒子：命中、爆炸、死亡；`TutorialGuide` 引导四页 |
| 周末 | 录一个 40 秒的演示视频，发给朋友看，问「哪里看不懂」 |

> 这周最容易犯的错：**素材风格不统一**（像素风塔 + 写实背景）。
> 建议统一用 itch.io 上的免费素材包（如 Kenney 的 Tower Defense 套件），一套全用，风格天然一致。

| 天 | 任务 |

| 周末 | 完整通关录像 + 截图 5 张（用于答辩和提交材料） |

- [ ] 打包后用 exe 跑一遍：**主菜单能进、能通关、能退出**

## 压缩版：只剩 2~3 周怎么办

砍顺序（从后往前砍）：

1. 只做 **1 个关卡场景**（但赛题要求 3 个 —— 这是硬伤，尽量别砍）
2. 特效只留「命中粒子 + 死亡音效」
3. 新手引导做成一张静态图（`Image` 贴说明图），不做分页
4. 灯光只加 `Global Light 2D`（不加氛围灯）
5. 美术全用色块 + 简单几何图形（**可以接受**，但要在 README 里说明「美术为占位」）

**绝对不能砍的**：3 种塔、3 种敌人（含特殊机制）、5 波、血条、暂停菜单四选项、胜负结算、淡入淡出、对象池。
这些是「基础内容」的硬指标，缺一条就是一个明确的扣分点。

## 增强版：想冲高分再加这些

按「30 秒内能演示」排序：

| 加分项 | 工作量 | 演示效果 |
|---|---|---|
| 波次预告（下一波敌人图标） | 半天 | 玩家能提前布防，显得专业 |
| 加速/暂停速度按钮（1×/2×） | 半天 | 老玩家很爽 |
| 塔的攻击目标优先级切换（最近/最远/最强） | 1 天 | 有深度 |
| 关卡内金币利息 / 提前召唤奖励 | 半天 | 有策略性 |
| Boss 波（血条在屏幕顶部的大怪） | 2 天 | 视觉冲击强 |
| 存档：最高波次记录 | 半天 | 有复玩动力 |
| 编辑器扩展：一键铺建造区 | 1 天 | 答辩时讲「工具链」很加分 |

同时做 3 个比做 1 个做一半好。**做完一个、跑通、录下来，再做下一个。**
