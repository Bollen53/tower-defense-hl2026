# A. 报错与现象速查

## A1. `NullReferenceException: Object reference not set to an instance of an object`

Unity 里 90% 的报错都是它。**排查顺序**：

1. 看 Console 里报错的行号，点一下会跳到对应脚本。
2. 问自己：这行用到的字段，**在 Inspector 里拖了吗**？
   - `[SerializeField] private TMP_Text goldText;` → 没拖就是 null
3. 是不是 `GetComponent<T>()` 拿不到？→ 说明那个组件没挂在**同一个物体**上（试试 `GetComponentInChildren`）。
4. 是不是单例还没创建？→ 把访问挪到 `Start()` 里，别放 `Awake()`。
5. 是不是对象已经被 `Destroy` 了但还在用？→ 用 `if (x != null)` 判断（**必须用 `!= null`，不能用 `is null`**，见 02 文档坑 1）。

## A2. 敌人不动 / 一出现就消失

| 可能原因 | 检查方法 | 修复 |
|---|---|---|
| 路径点没拖 | 选中 `Path`，看 `points` 数组是不是空 | 把 `P0…Pn` 按顺序拖进去 |
| 路径点数量 < 2 | Console 有 `[WaveManager] WaypointPath 至少要有 2 个路径点` | 至少两个点 |
| 敌人预制体没挂 `Enemy` / `EnemyHealth` | Console 有对应 Error | 挂上 |
| `EnemyData` 没拖进 `WaveManager` 的波次 | 看 `LevelWaves` 资产里 `groups[].enemy` 是否为空 | 拖敌人数据 |
| 游戏处于暂停/失败状态 | 看 HUD 和 `Time.timeScale` | 恢复 Playing |
| `moveSpeed` 设成 0 | 看 EnemyData | 改回 1.5 |
| 敌人物体 `scale = 0` | 看 Inspector | `EnemyData.scale` 别设 0 |

## A3. 塔不开火 / 只朝一个方向

| 原因 | 修复 |
|---|---|
| `range` 太小，敌人根本没进范围 | 临时把 `range` 调到 10 验证 |
| 敌人没注册进 `EnemyRegistry` | 检查预制体上有没有 `Enemy` 脚本；`Enemy.Setup` 有没有被执行（加 `Debug.Log`） |
| 塔的 `Data` 为空（不是通过 `BuildManager` 建的） | 手动建的塔必须调 `Setup(data, tile)`，或者干脆用建造流程建 |
| `turret` / `body` 没拖 | 拖上；`turret` 为空只是不转，不影响开火 |
| `fireInterval` 设得极大 | 检查塔数据 |

## A4. 子弹不出现 / 停在原地 / 不追踪

| 原因 | 修复 |
|---|---|
| `TowerData.projectilePrefab` 没拖 | 拖 `Projectile_Arrow` 等 |
| 子弹预制体上没有 `Projectile` 脚本 | Console 有 `[Tower] 子弹预制体上没有 Projectile 脚本` |
| 场景里没有 `PoolManager` | 有 `[WaveManager] 场景里缺 PoolManager` 报错；加一个 |
| `projectileSpeed = 0` | 改回 7~12 |
| 子弹一生成就掉在原点 | 检查 `Tower.firePoint` 是否在塔内部（位置对但看不见）——把排序调到 12 以上 |

## A5. 点击地块建不了塔

按这个顺序查，**几乎是前三条之一**：

1. **地块有没有 `BoxCollider2D`？** `Physics2D.OverlapPoint` 只能查到有碰撞体的东西。
2. **地块的 Layer 是不是 `BuildTile`？`BuildManager.tileMask` 有没有勾这一层？**
   两者不匹配 = 永远查不到。
3. **是不是点到了 UI？** `EventSystem.current.IsPointerOverGameObject()` 会挡住。
   如果你点的位置被一个透明的全屏 Image 盖住（很常见！），也会失效——
   把那个 Image 的 `Raycast Target` 取消勾选。
4. 有没有先选塔？`SelectedData == null` 时点地块只会提示「先在下方选一座塔」。
5. 金币够不够？HUD 上的数字 vs 塔的 `BuildCost`。

## A6. UI 按钮点不动 / 点地图却触发了按钮

- Canvas 上必须有 `Graphic Raycaster`（删了就没法点）。
- 场景里必须有 `EventSystem` 物体（删了全场景 UI 都点不动）。
- 装饰性图片/文字把 `Raycast Target` 取消，否则它会挡住下面的按钮。
- 按钮的 `Interactable` 是否被代码关掉了（`BuildButton` 会在钱不够时自动关）。

## A7. 血条不跟着掉 / 一直是满的

| 原因 | 修复 |
|---|---|
| `WorldHealthBar.health` 没拖 | 拖 Enemy 上的 EnemyHealth |
| `fill` 没拖 | 拖 Fill 子物体 |
| 血条是 `Image` 而不是 `SpriteRenderer` | 本脚本用的是 `Transform.localScale`，`Image` 也能用，但要拖它的 Transform 且设成 `Filled` 模式不行——建议用 SpriteRenderer |
| 敌人没受伤 | 看 Console，塔有没有开火 |

## A8. 切场景黑屏 / 卡住

| 原因 | 修复 |
|---|---|
| 场景没加进 `Build Settings` | `File > Build Settings > Add Open Scenes`，四个场景都要有 |
| 场景名拼错 | `LevelConfig.SceneNames` 里的名字必须**和场景文件名完全一致**（含大小写） |
| `SceneFader` 的 `busy` 卡住 | 加载失败会一直黑；看 Console 有没有 `Scene ... couldn't be loaded` |
| 编辑器里直接 Play 当前场景，`GameManager` 缺失 | 单独 Play `Level_01` 是支持的（GameManager 在场景里），但 Play `MainMenu` 就别期望有生命值 |

## A9. 中文全部显示成方块 / 问号

**TMP 默认字体不含中文**，必须自己做字体资产。步骤：

1. 下载一个开源中文字体（**注意许可证**）：思源黑体 `SourceHanSansSC`、霞鹜文楷 `LXGWWenKai`、阿里普惠体。
2. 把 `.ttf` / `.otf` 拖进 `Assets/_Project/Art/Fonts/`。
3. 菜单 `Window > TextMeshPro > Font Asset Creator`：
   - `Source Font File` 选刚拖进来的字体
   - `Sampling Point Size`：Auto Sizing
   - `Padding`：5
   - `Atlas Resolution`：2048 × 2048
   - **`Atlas Population Mode`：Dynamic**（关键，这样运行时遇到没预生成的字会自动加进来，
     不用手工列 3500 个常用字）
   - `Render Mode`：SDFAA
4. 点 `Generate Font Atlas` → `Save as...` 存到 `Assets/_Project/Art/Fonts/`，例如 `SourceHanSansSC_SDF`。
5. 选中所有 TMP 文本，把 `Font Asset` 换成这个新资产。
   （或 `Project Settings > TextMeshPro > Settings > Default Font Asset` 全局替换）

> 用 Dynamic 模式后，打包时字体文件要一起进包，通常没问题；如果发布后发现缺字，
> 检查 `Atlas Population Mode` 是不是被改回了 Static。

## A10. 画面全黑 / 加灯没反应

- 场景里没有 `Global Light 2D` → 加一个，`Intensity = 1`。
- Sprite 的 Material 是 `Sprite-Unlit-Default` → 换成 `Sprite-Lit-Default`。
- 相机 `Background` 是纯黑 + 摄像机没对准地图 → 按 `F` 聚焦物体看看。
- URP 的 `Renderer` 不是 `2D Renderer` → `Project Settings > Graphics > Scriptable Render Pipeline Settings`
  里的 URP Asset，检查 `Renderer List` 是 2D Renderer。

## A11. 暂停后整个游戏再也不动了

- 你在暂停时退出了场景：`Time.timeScale` 停在 0。
  本套 `PauseMenu` / `TutorialGuide` 都在 `OnDestroy` 里做了兜底，但**自己新写的脚本要注意**。
- 编辑器里 Play 前手动改过 `Time.timeScale`？重启 Play 即可。

## A12. `InvalidOperationException: You are trying to read Input using the UnityEngine.Input class...`

工程用的是新版 Input System，代码用的是旧版 `Input`。
→ `Project Settings > Player > Other Settings > Active Input Handling` 改成 **Both**，重启编辑器。

## A13. `CS0246: The type or namespace name 'TMPro' could not be found`

TMP 资源没导入：`Window > TextMeshPro > Import TMP Essential Resources`。

## A14. 敌人从池子里取出来后「卡在原地」或「血条错乱」

对象池复用必须重置状态。本套代码在 `Enemy.Setup` 里重置了全部字段（位置、速度、减速、特殊计时、血条）。
如果你自己加了新字段，**记得在 `Setup` 里也重置**，否则会出现「上一只怪的残留状态」。

## A15. `MissingReferenceException` / `GameObject is already being destroyed`

通常是：协程还在跑，但它引用的物体已经被销毁。
→ 协程开头加 `if (this == null) yield break;`，或者在该物体销毁时 `StopAllCoroutines()`。

## A16. 按 Esc 完全没反应（暂停菜单打不开）

| 原因 | 修复 |
|---|---|
| `PauseMenu` 的 `panel` 拖成了**自己** | 本套脚本要求脚本挂在常驻物体上、`panel` 指向子 Panel。拖错时 Console 会报 `[PauseMenu] panel 必须指向一个子面板`，按提示改 |
| 场景里根本没有 `PauseMenu` 物体 | 加一个空物体挂脚本 |
| 游戏已经 Won/Lost | 这是设计如此（结算后不再允许暂停） |
| 新手引导正在显示 | 引导期间 Esc 被屏蔽（代码里 `TutorialGuide.IsShowing`），引导结束就好 |

## A17. 设置 / 塔信息 / 结算面板「点了没反应」

这三块是同一类问题，**根因都是「脚本挂在了默认隐藏的物体上」**：

> Unity 不会对未激活的物体执行 `Awake` / `Start`。
> 脚本挂在隐藏面板上 → Awake 不跑 → 按钮监听没绑上 → 点按钮毫无反应，Console 干净。

本套代码的统一约定：**脚本挂在常驻空物体上，只把子 `Panel` 关掉**（见 04 文档 D2）。
拖错成「panel = 自己」时，脚本会在 `Awake` 里直接报错并禁用自己，不会静默失效。

| 现象 | 检查 |
|---|---|
| 点「设置」没反应 | `SettingsPanel` 物体的 `panel` 指向子 Panel；`MainMenu.settingsPanel` 拖的是这个脚本 |
| 点塔没有信息面板 | `BuildManager.infoPanel` 拖了吗；`TowerInfoPanel.panel` 是否指向子 Panel |
| 打赢了不弹结算 | `ResultPanel` 物体是否被关掉了；`ResultPanel.panel` 是否指向子 Panel；Console 有没有 `[ResultPanel] 场景里找不到 GameManager` |

## A18. 打完最后一波，游戏静止但没有任何提示

- `ResultPanel.panel` 没拖 / 拖成了自己 → 面板弹不出。
- `GameManager.WinGame` 没被调用：看 Console 有没有 `[WaveManager] ...` 的 Error，
  或者 `LevelWaves` 里波数配成了 0（本套会直接禁用 WaveManager 并报错）。
- `GameManager` 不在场景里 → `WinGame` 里 `Instance` 为 null，静默跳过。

## A19. 敌人走到终点后「消失但没扣血」

- `Enemy.ReachBase` 里 `Data.damageToBase` 设成了 0。
- HUD 的生命文本没拖（数据变了但没显示）——先看 Inspector 里 `GameManager.Lives` 有没有变。

# C. 性能与稳定性

打第 5 波时开 `Window > Analysis > Profiler`：

| 指标 | 正常范围 | 偏高怎么办 |
|---|---|---|
| FPS | 60 稳定 | 掉帧就查 Draw Call 和 GC |
| GC Alloc（每帧） | < 1 KB | 每帧几百 KB 说明有 `new` 或字符串拼接在 Update 里 |
| Draw Calls | < 100 | Sprite 合批被打破（材质不同/排序穿插） |

常见 GC 来源（本套代码已规避）：
- `Update` 里 `GetComponent` → 改成 `Awake` 缓存
- `Update` 里 `string` 拼接 → 本套的 HUD 只在数值变化时更新文本
- 每帧 `new List` → 本套用静态 buffer 复用（`Enemy.healBuffer`、`Projectile.splashBuffer`）
- `Instantiate/Destroy` 子弹 → 已用对象池
