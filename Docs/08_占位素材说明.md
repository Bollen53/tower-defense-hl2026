# 08 占位素材说明（含导入设置）

> `Assets/Art/Placeholder/` 里是 18 张纯几何图形，**风格统一、可直接用**。
> 目的不是好看，是让你在没有任何美术资源的情况下，第一天就能把场景搭出个样子。
> 正式素材到位后，**保持文件名不变直接覆盖**，Unity 里的引用不会断。

## 二、怎么接到预制体上

对应 `04_预制体与场景装配手册.md` 的 B 节，把「用内置 Square」换成这里的图：

| 预制体 / 位置 | 用哪张图 |
|---|---|
| `BuildTile` → Base | `tile_ground` |
| `BuildTile` → Highlight | 还是用内置 Square，染成绿色（或复制一份 `tile_ground` 调色） |
| `RangeIndicator` → Circle | `vfx_range_circle` |
| `Enemy` → Body | 四个敌人各一张（同一个预制体，运行时由 `EnemyData.sprite` 换） |
| `Enemy` → HealthBar/Bg、Fill | `ui_health_bg` / `ui_health_fill` |
| `Tower` → Body | `tower_*_base` |
| `Tower` → Turret/TurretSprite | `tower_*_head` |
| `Projectile_*` | `proj_arrow` / `proj_cannon` / `proj_frost` |
| Canvas 里所有面板底图 | `ui_panel`（Sliced） |

血条尺寸建议（SpriteRenderer 的 Transform）：
```
HealthBar  位置 (0, 0.55, 0)
├─ Bg      localScale (1, 1, 1)       → 0.64 × 0.12 世界单位
└─ Fill    localScale (0.95, 0.6, 1)  → 略小于底条，留一圈描边
```

## 三、换成正式素材时

1. **保持文件名**：直接覆盖 `Assets/Art/Placeholder/` 里的同名文件，Unity 会自动重新导入，所有引用都还在。
2. **保持 PPU 语义**：新图如果尺寸不同，把 PPU 设成 `图片宽度 / 期望的世界单位宽度`。
   例如新塔底座 256px、希望 1 单位宽 → PPU = 256。
3. **别改 pivot 约定**：底座 Center、炮塔头 Bottom、子弹 Center。改了会出现「塔歪着转」「子弹绕圈飞」。
4. 做完把 `Assets/Art/Placeholder/` 整个文件夹改名为 `Assets/Art/`（或把新图放 `Assets/Art/Final/`），避免答辩时被看到"占位"字样。

## 四、想自己改颜色重画

`Tools/make_placeholder_art.py` 是生成脚本（用 Pillow）。改文件顶部的 `C` 调色盘后重跑：

```powershell
# 需要装了 Pillow 的 Python
python Tools/make_placeholder_art.py
```

三个塔的主题色在文件末尾：`tower_base(C["wood_l"], ...)` / `C["iron_l"]` / `C["frost"]`。

> 这套素材是程序生成的，**不算「他人素材」**，不用登记到 `素材来源.md`。
> 但如果正式版用了别人的图，记得回去补那一份表。
