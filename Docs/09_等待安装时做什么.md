# 09 等待安装时做什么（90 分钟时间盒）

> Unity 下载 + 安装通常 40~90 分钟（视网速）。这段时间**别刷手机**，下面 4 件事都不需要 Unity，
> 而且每一件后面都要做，现在做等于白赚。
> 按顺序做，每段结束就打个勾。

---

## T+0 ~ 25 分钟：把 GitHub 仓库搭起来

赛题要求「全程提交至 GitHub 仓库」，**commit 的时间线本身就是你在做项目的证据**。
插件、素材、代码都还没开始，正好先把仓库建好，第一条 commit 就写「初始化项目」。
这样从第一天起就有记录，而不是最后一天一次性上传 300 个文件。

### 1. 建仓库

GitHub → `New repository` →
- 名称：`tower-defense-hl2026`（或你喜欢的）
- 可见性：**Public**（私有仓库评委看不到，除非单独加人）
- **不要**勾 "Add a README"（本地已经有了，避免冲突）

### 2. 本地初始化（PowerShell）

```powershell
cd D:\Unity\TowerDefense        # 换成你准备放工程的位置，路径别带中文
git init
git branch -M main
```

把 `TowerDefenseKit/gitignore_unity.txt` 复制到工程根目录，**改名为 `.gitignore`**：

```powershell
Copy-Item "C:\Users\lbw13\Documents\deepseek-harness\default-workspace\TowerDefenseKit\gitignore_unity.txt" .gitignore
```

### 3. 先把「不依赖 Unity 的东西」提交一次

```powershell
# 把资料文档也放进来，评委会看
New-Item -ItemType Directory -Force Docs, Tools | Out-Null
Copy-Item "C:\Users\lbw13\Documents\deepseek-harness\default-workspace\TowerDefenseKit\Docs\*.md" Docs\
Copy-Item "C:\Users\lbw13\Documents\deepseek-harness\default-workspace\TowerDefenseKit\Tools\*.py" Tools\

git add .
git commit -m "chore: 初始化项目结构与开发计划文档"
```

### 4. 关联远端并推送

```powershell
git remote add origin https://github.com/<你的用户名>/tower-defense-hl2026.git
git push -u origin main
```

> ⚠️ 第一次 push 会让你登录。推荐用 **Personal Access Token**（GitHub → Settings → Developer settings →
> Personal access tokens → Fine-grained tokens → 勾 `Contents: Read and write`），
> 密码框里粘贴 token。或者装 GitHub Desktop / `gh` CLI，更省事。

### 5. 建一个 `开发日志.md`

以后每天 commit 完，在日志里加一行「日期 + 今天做完什么 + 明天做什么」。
答辩被问「你每天在干什么」时，这份日志 + commit 历史就是最硬的证据。

## T+25 ~ 50 分钟：把素材一次性下齐

**这一步必须现在做**，因为素材下载经常踩坑（链接失效、许可证不清、格式不对），
真到你搭场景时才发现没图，会卡一整晚。

### 建议直接用的资源（风格统一，省得后期重做）

| 用途 | 推荐 | 说明 |
|---|---|---|
| 2D 塔防美术 | <https://kenney.nl/assets/tower-defense-kit> | **CC0**，一套齐全（塔/敌人/子弹/地块），风格统一 |
| UI 元素 | <https://kenney.nl/assets/ui-pack> | 按钮、面板、图标 |
| 音效 | <https://kenney.nl/assets/interface-sounds>、<https://freesound.org> | 建造/攻击/死亡 |
| 背景音乐 | <https://pixabay.com/music/>、<https://incompetech.com> | 菜单 + 战斗各一首 |
| 中文字体 | <https://github.com/adobe-fonts/source-han-sans> 或霞鹜文楷 <https://github.com/lxgw/LxgwWenKai> | **必须有**，否则 UI 全是方块 |

### 下来之后立刻做两件事

1. **按用途重命名**，别留 `kenney_rocks_01.png` 这种名字：
   `tower_arrow_base.png`、`enemy_grunt.png`、`sfx_build.wav`……
   （名字和 `08_占位素材说明.md` 的表对得上，后面替换零成本）
2. **打开 `Docs/素材来源.md` 逐条填**：链接、作者、许可证、是否修改。
   这活儿现在做 10 分钟，等答辩前一天做就是两小时，还可能记不清来源。

> 许可证优先级：**CC0 > CC-BY（要署名）> 仅限个人使用（不要用）**。
> 看到 "non-commercial" 一律跳过——比赛作品通常算公开演示。

## T+50 ~ 75 分钟：纸上把三关设计出来

这是**最省时间的一步**。在 Unity 里拖格子很慢，在纸上（或 Excel）画路径只要五分钟，
而且能提前发现「路径太短，塔来不及打」「建造区离路太远，塔够不着」这类**搭完才发现的设计错误**。

用 `Docs/关卡布局工作表.md`，填三张表：

1. 每关的**路径点坐标**（8 个左右的转折点）
2. 每关的**建造区范围**（哪些格子可以建）
3. 每关的**5 波敌人配置**（用哪种敌人、几只、间隔多少）

填完你会得到类似这样的东西，后面直接照着在 Unity 里摆：

```
Level_01 路径: (-9,4) → (-6,4) → (-6,-3) → (-1,-3) → (-1,4) → (4,4) → (4,-3) → (9,-3)
总长 39 单位，步兵速度 1.5 → 单程 26 秒
```

> 悄悄说：把这张表填好，等 Unity 装完，我可以写一个编辑器脚本**直接按坐标生成地块和路径点**，
> 你就不用手工拖 100 个格子了。所以现在填得越准，后面越省事。

## T+75 ~ 90 分钟：读代码，跟着一只怪走一遍

不用 Unity 也能读代码（记事本 / VS Code 都行）。**别从 `GameManager` 开始读**，
按「一只敌人从出生到死亡」的顺序读，最容易建立整体感：

| 站点 | 读哪个文件 | 读完要能回答 |
|---|---|---|
| ① 出生 | `Wave/WaveManager.cs` 的 `SpawnEnemy` | 敌人是从哪来的？为什么用 `PoolManager.Spawn` 而不是 `Instantiate`？ |
| ② 登记 | `Enemy/EnemyRegistry.cs` 的 `Register` | 为什么要有这张表？塔不查它会怎样？ |
| ③ 走路 | `Enemy/Enemy.cs` 的 `Move` | `Vector2.MoveTowards` 和「速度乘 deltaTime」各解决什么问题？ |
| ④ 挨打 | `Enemy/EnemyHealth.cs` 的 `TakeDamage` | 护甲为什么用「减去固定值」而不是「乘以百分比」？ |
| ⑤ 开火 | `Tower/Tower.cs` 的 `Update` + `Fire` | 塔怎么挑目标？为什么挑「最接近终点」的？ |
| ⑥ 死亡 | `Enemy/Enemy.cs` 的 `HandleDied` | 金币是谁发的？谁负责把敌人回收进池子？ |

读完这 6 处，你已经掌握了整个项目 60% 的逻辑。
剩下的（UI、升级、存档）都是在这条主线上挂东西。

接着做 `02_CSharp速成.md` 第 6 节的 **Day 1 三个练习**（改数值、加日志、改初始金币）。
这些改动等 Unity 装好第一件事就能验证，正好用来确认「我确实会改代码了」。

## 如果 90 分钟了你还没装完

继续等，但换一件事做：**把 `07_答辩与代码讲解卡.md` 过一遍**。
里面每个脚本都有一句话总结和「可能被问什么」，现在读一遍，
等真写代码时你会带着「这段以后要怎么解释」的意识去写，比事后补强太多。

---

## 装完之后的第一件事（别搞错顺序）

1. 新建 **Universal 2D** 工程（不是 Built-in）
2. 导入 TMP Essential Resources
3. `Active Input Handling` 改成 **Both**
4. 把 `Assets/Scripts` 和 `Assets/Art` 拖进去，等编译
5. **Console 必须是干净的**，然后才进 `04` 文档

一次只做一步，每步都看一眼 Console。新手最常犯的错是「一口气全拖进去，报错一堆不知道哪个引起的」。
