# 12 自己动手任务清单（8 个功能，从易到难）

> 目的很直接：**让仓库里有一部分代码确实是你写的**，而且是你自己调试出来的。
> 每个任务都给了「需求 / 验收标准 / 从哪下手 / 会踩什么坑」。
>
> 原则：**不要改现有代码来"留指纹"**，要**加新功能**。加功能留下的 commit 记录、
> 调试过程、和你自己的理解，才是别人拿不走的。
>
> 建议顺序：**1 → 3 → 5**（这三个做完，答辩就有完整故事了）。

## 任务 1：击杀数统计（30 分钟）★

**需求**：HUD 上显示「击杀 12」。

**验收标准**
- [ ] 打死 3 只怪，数字变成 3
- [ ] 重开本关，归零
- [ ] Console 无报错

**从哪下手**
1. `GameManager` 加 `public int KillCount { get; private set; }` 和 `public event Action<int> KillCountChanged;`
2. 加 `public void AddKill()` → 自增 + 触发事件
3. `Enemy.HandleDied` 里调 `GameManager.Instance.AddKill()`
4. `HUD` 加一个 `TMP_Text killText`，`Start` 里订阅、`OnDestroy` 里退订

**坑**：忘了在 `OnDestroy` 里 `-=`，重开时会出现「数字跳两下」——因为旧的 HUD 还在收事件。

**提交**：`feat: 加入击杀数统计并在 HUD 显示`

---

## 任务 2：1×/2× 加速按钮（1 小时）★★

**需求**：HUD 上加一个按钮，点击在 1 倍速 / 2 倍速间切换，按钮文字跟着变。

**验收标准**
- [ ] 点一下敌人明显变快，再点恢复正常
- [ ] 加速状态下按 Esc 暂停，再继续，**仍然是 2 倍速**（不是被重置成 1）
- [ ] 结算界面出现时，速度回到 1

**从哪下手**
- `GameManager` 加 `public float SpeedMultiplier { get; private set; } = 1f;`
- `SetSpeed(float m)` → 存起来，如果当前不是暂停状态就 `Time.timeScale = m`
- **关键**：`SetPaused(false)` 里把 `Time.timeScale = paused ? 0f : SpeedMultiplier`，而不是写死 `1f`
- HUD 里加按钮，点击切换并更新文字（`"1×" / "2×"`）

**坑**：`GameManager.RestartLevel` / `WinGame` 里也有 `Time.timeScale = 1f`，记得一起改成 `SpeedMultiplier`，否则重开后倍速丢了。

**提交**：`feat: 加入 1x/2x 倍速切换`

---

## 任务 3：塔的目标优先级切换（2 小时）★★

**需求**：选中塔后，信息面板出现三个按钮——「最前 / 最近 / 最强」，当前模式高亮。

**验收标准**
- [ ] 三座塔分别设成不同模式，打的目标肉眼可见不同
- [ ] 切换后立即生效（不用重建塔）
- [ ] 重开游戏，塔默认是「最前」

**从哪下手**
1. 新建枚举 `public enum TargetMode { Furthest, Nearest, Strongest }`
2. `EnemyRegistry` 再加两个查找方法（或给 `FindBestTarget` 加一个 `TargetMode` 参数）：
   - `Nearest`：比距离 `sqrMagnitude`
   - `Strongest`：比 `Health.Max`
   - `Furthest`：比 `Progress`（现有的逻辑）
3. `Tower` 加 `[SerializeField] private TargetMode mode = TargetMode.Furthest;`，
   `Update` 里按 `mode` 调对应查找
4. `TowerInfoPanel` 加三个按钮 → 调 `tower.SetTargetMode(mode)`

**坑**：`EnemyRegistry` 里现有方法会顺手清理 null（`Prune`），你新加的方法**也要清理**，
否则波次结束时静态列表残留会导致波次永远不结束。**这是这个任务最值钱的坑，踩过一次你就真懂了。**

**提交**：`feat: 塔支持最前/最近/最强三种索敌策略`

## 任务 4：波次预告面板（2 小时）★★

**需求**：布防倒计时期间，屏幕上显示「下一波：步兵 ×6　疾行者 ×4」。

**验收标准**
- [ ] 倒计时开始就显示，出怪瞬间消失
- [ ] 内容与实际刷怪一致
- [ ] 最后一波时显示「最后一波」

**从哪下手**
- `WaveManager` 加一个只读属性返回下一波的 `Wave` 对象（注意：当前波 index + 1）
- `HUD` 订阅 `WaveChanged` 时顺便刷新预告；`CountdownChanged` 到 0 时隐藏

**坑**：数组越界——最后一波时 `index + 1` 不存在，要判 `HasNext`。

**提交**：`feat: 布防阶段显示下一波敌人预告`

---

## 任务 5：提前召唤下一波（2 小时）★★★

**需求**：倒计时期间出现按钮「提前召唤（+N 金币）」，点击立即出怪，按剩余秒数给奖励。

**验收标准**
- [ ] 点击后立即出怪，倒计时消失
- [ ] 金币增加 `Mathf.FloorToInt(剩余秒数 × 2)`，HUD 数字同步
- [ ] 连点两次不会召唤两波（按钮点击后立即禁用）
- [ ] 不点也能正常倒计时出怪

**从哪下手**
- `WaveManager.Prep` 协程里加一个 `bool skipRequested`；
  每帧检查，为真就 `break` 出循环
- 加 `public void RequestNextWave(float remainingBonus)` → 设标志 + `GameManager.AddGold(...)`
- 注意：奖励要在**按下瞬间**按当时的 `Countdown` 算，不能等协程退出再算

**坑**：`while (t > 0f)` 里 break 之后别忘了把 `Countdown` 置 0 并广播一次，否则 HUD 会一直显示「下一波 3」。

**提交**：`feat: 支持提前召唤下一波并按剩余时间奖励金币`

---

## 任务 6：最高波次存档（1 小时）★

**需求**：记录每关「到达过的最高波次」，关卡选择界面显示「第一关 · 最佳 4 波」。

**验收标准**
- [ ] 打到第 3 波失败，回主菜单再进，显示最佳 3 波
- [ ] 超过旧记录才更新，不会退回
- [ ] 三关各自独立记录

**从哪下手**
- `SaveSystem` 加 `GetBestWave(int levelIndex)` / `SetBestWave(int levelIndex, int wave)`，
  key 用 `td_best_wave_{index}`
- `WaveManager.WaveChanged` 里更新
- `LevelSelectPanel` 刷新按钮文字

**提交**：`feat: 记录并显示各关最高波次`

## 任务 7：Boss 波 + 顶部血条（4 小时）★★★

**需求**：第三关最后一波出现一个 Boss：体型 2 倍、血量 1200、护甲 10、移动慢，
屏幕顶部显示它的血条和名字；Boss 死亡立即宣告胜利。

**验收标准**
- [ ] Boss 出现时顶部血条出现，受击实时下降
- [ ] Boss 死或到达终点，血条消失
- [ ] 小怪死了不影响顶部血条

**从哪下手**
- `EnemyData` 加 `public bool isBoss;`
- `Enemy` 加 `public bool IsBoss => Data != null && Data.isBoss;`
- 新建 `BossHealthUI`：订阅场上 Boss 的 `EnemyHealth.HealthChanged`
- 找 Boss：遍历 `EnemyRegistry.All` 找第一个 `IsBoss`

**坑**：Boss 从对象池复用时，`HealthChanged` 会重复订阅 —— 参考 `Enemy.Setup` 里「先 `-=` 再 `+=`」的写法。

**提交**：`feat: 加入 Boss 敌人与顶部血条`

## 任务 8：编辑器扩展——一键铺建造区（3 小时）★★★

**需求**：菜单 `Tools > TD > 生成建造区`，弹窗输入 x / y / 宽 / 高，一键生成一片 `BuildTile`。

**验收标准**
- [ ] 输入 `x=-5 y=-2 w=4 h=6` 生成 24 个地块，位置正好对上（参考关卡布局工作表）
- [ ] 生成后 `Ctrl+Z` 能撤销
- [ ] 脚本放在 `Assets/Editor/` 目录下

**从哪下手**
```csharp
using UnityEditor;
using UnityEngine;

public class BuildTilePainter : EditorWindow
{
    [MenuItem("Tools/TD/生成建造区")]
    static void Open() => GetWindow<BuildTilePainter>("建造区生成器");

    // 字段：tilePrefab、parent、startX、startY、width、height
    // OnGUI 里画输入框 + 按钮
    // 生成时：Undo.RegisterCreatedObjectUndo + Instantiate + 设坐标
}
```

**为什么这个任务最加分**：它证明你会用 Unity 的工具链，而不只是会写游戏逻辑。
答辩时说「我写了个工具，一次生成一关的建造区，省了 40 分钟手工摆放」——
这句话的分量比十个游戏功能都重。

**提交**：`feat: 添加建造区批量生成编辑器工具`

## 做完之后

每个任务完成后做三件事：

1. **提交**，message 用上面的格式
2. 在 `Docs/开发日志.md` 加三行：做了什么 / 卡在哪 / 明天做什么
3. 如果卡过，在 `Docs/Bug记录.md` 记一条（**这条最值钱**）

然后在 `Docs/11_怎样证明这是你自己做的.md` 的 README 模板里，
把「我独立完成的部分」改成真实内容——**那时候它就是真的了。**
