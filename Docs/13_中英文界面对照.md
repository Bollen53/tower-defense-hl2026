# 13 中英文界面对照

> 本套文档里的菜单路径是**英文**的（因为网上教程、报错信息、搜索关键词都是英文）。
> 如果你把编辑器切成了中文，用这张表对照着找。
>
> **建议**：界面用中文没问题，但**术语一定要记住英文**——以后搜「Unity Sorting Order 不生效」
> 比搜「Unity 排序图层 不生效」有用十倍。

---

## 一、切换语言

`Edit` → `Preferences...`（或 `Ctrl+,`）→ 左侧 **`Languages`** → `Editor Language` 选 **中文（简体）** → 重启。

想切回来：同样位置选 `English`。

## 八、Resource 与报错关键词

| 英文报错片段 | 中文含义 |
|---|---|
| `NullReferenceException` | 空引用：某个字段没拖、或对象已被销毁 |
| `The type or namespace name 'TMPro' could not be found` | 没导入 TMP 资源 |
| `You are trying to read Input using the UnityEngine.Input class` | 输入系统设置不对，改 Active Input Handling = Both |
| `Coroutine couldn't be started because the game object is inactive` | 物体被关闭了，协程启动不了 |
| `MissingReferenceException` | 引用的对象已被销毁 |
| `Scene 'xxx' couldn't be loaded` | 场景没加进 Build Settings |

---

## 最后一句

界面选中文没问题，但**搜索报错时用英文原文**。中文翻译有时候不准确（比如 `Sorting Order` 在不同版本译法不同），
而英文关键词能搜到官方文档和 Stack Overflow 的原始答案。
