## 0. 比赛要求里和你（菜单）相关的部分

来源：**2026 绘蓝杯游戏开发赛题（B 组）· 题目一 2D 塔防**。
「基础内容」是**硬性全部实现**，缺一条就是一个明确的扣分点。

### 通用规则（和你直接相关）

| 要求 | 对你的影响 |
|---|---|
| **必须使用 Unity 引擎** | 不能换引擎/不能做网页版 |
| 素材可用网上的，也可自制 | 但你用的图/字体/音乐**必须登记来源**（见 `Docs/素材来源.md`） |
| 允许 AI 辅助，但必须对自己的代码负责 | 每段代码你要能解释「为什么这么写」 |
| 插件使用前先询问 | 想装 DOTween 之类的先问队友，别自己装 |
| 全程提交至 GitHub | 用你自己的账号 commit，`git log` 里要能看到你的提交 |

### 基础内容里和你有关的 5 条

| 赛题原文 | 你负责的部分 |
|---|---|
| 游戏流程完整：主菜单、关卡内游玩、胜负结算、重新挑战 | **主菜单 + 关卡选择**；结算和重开在关卡内，归队友 |
| 制作开始与结束的 UI 界面 | 主菜单就是「开始 UI」；结束 UI 归队友，但你要保证能从菜单进关卡 |
| 暂停菜单：暂停 / 回主菜单 / 设置 / 返回游戏 | 面板归队友，但**「设置」面板是你俩共用的**（`SettingsPanel.cs`） |
| 场景切换流畅，切换时要使用**淡入淡出**效果 | **必须走 `SceneFader.Instance.LoadScene(...)`**，不要直接调 `SceneManager` |
| 至少制作三个可以游玩的场景（只含新手教程的小场景除外） | 关卡选择面板要能进 **3 个**关卡，并且不锁住已解锁的 |
| 音效：背景音乐 | 菜单 BGM（`PlayMenuMusic`）+ 按钮点击音效（`PlaySfx(Sfx.Click)`） |
| 新手引导（方式不限，可以是界面 UI 帮助组件） | **加分项**：主菜单加一个「玩法说明」入口，成本极低 |

### 进阶内容里值得你顺手拿的分

| 进阶项 | 你怎么做 |
|---|---|
| 存档（PlayerPrefs / JsonUtility） | 关卡解锁、音量**直接用 `SaveSystem`**，不要自己写一套 |
| 设计模式（单例 / 观察者） | 菜单里访问 `Instance` 就是单例；按钮订阅事件就是观察者 |
| 代码职责划分 | 一个脚本只干一件事：`MainMenu` 管流程、`LevelSelectPanel` 管关卡列表、`SettingsPanel` 管音量 |

### 三条「别做的事」

1. **不要自己写 GameManager / 存读档 / 场景管理器**——已有现成的，重复实现会打架。
2. **不要改 URP 渲染设置**——整个画面可能全粉。
3. **不要用 UI Toolkit**——项目全部 UI 是 UGUI，混用会出现两套字体/两套事件系统。

## 3. 你可以依赖的接口（已冻结，**不要改这些文件**）

```csharp
// ── 关卡列表与加载 ──
LevelConfig.SceneNames          // string[]  例：{"Level_01","Level_02","Level_03"}
LevelConfig.DisplayNames        // string[]  例：{"第一关 · 山谷小径", …}
LevelConfig.Descriptions        // string[]
LevelConfig.Count               // int
LevelConfig.MenuSceneName       // const string = "MainMenu"
LevelConfig.IsLevelUnlocked(i)  // ❌ 不存在，用 SaveSystem
LevelConfig.HasNext(i)          // bool
LevelConfig.LoadLevel(i)        // 带淡入淡出进第 i 关（越界会 clamp）

// ── 场景切换（统一入口，别直接调 SceneManager） ──
SceneFader.Instance.LoadScene("MainMenu");

// ── 存档 ──
SaveSystem.UnlockedLevel            // int，已解锁的最高关下标
SaveSystem.IsLevelUnlocked(i)       // bool
SaveSystem.UnlockLevel(i)           // 一般在通关时由 GameManager 调
SaveSystem.TutorialDone             // bool
SaveSystem.MasterVolume             // float 0~1（改了不会立刻写盘）
SaveSystem.MusicVolume              // float 0~1
SaveSystem.Flush()                  // 把设置写盘（关面板时调一次）

// ── 音频 ──
AudioManager.Instance.PlayMenuMusic();
AudioManager.PlaySfx(Sfx.Click);        // Sfx: Click/Build/Upgrade/Sell/TowerShoot/EnemyDeath/BaseHit/WaveStart/Win/Lose
AudioManager.Instance.ApplyVolume();    // 改完音量调一次

// ── 单局状态（主菜单里一般不需要） ──
GameManager.Instance.State              // Playing / Paused / Won / Lost
GameManager.Instance.RestartLevel() / BackToMenu() / GoToNextLevel()
```

> 已有的 `MainMenu.cs`、`LevelSelectPanel.cs`、`SettingsPanel.cs` 你可以**直接改**（它们归你）。

## 4. 你的边界

### ✅ 你要做

- `Assets/Scenes/MainMenu.unity`（**你独占**，别动 `Level_01~03`）
- `Assets/UI/` 下的一切：菜单脚本、UI 预制体、图片、字体
- 主菜单 / 关卡选择 / 设置 / 制作人员

### ❌ 你不要做

| 不要碰 | 原因 |
|---|---|
| `Assets/Scripts/Core|Enemy|Tower|Wave/` | 你改了队友的代码会编译失败 |
| `Assets/Scenes/Level_*.unity` | 场景没法合并，谁改谁重做 |
| `ProjectSettings/EditorBuildSettings.asset`（Build Settings） | 单文件，只由队友改。**你的场景名告诉他，他加** |
| `ProjectSettings/TagManager.asset`（图层/Tag） | 同上 |
| `Packages/manifest.json` | 装包前先说 |
| `Assets/Settings/*`（URP 配置） | 改错了整个画面全粉 |

## 5. 命名与目录约定

```
Assets/
├─ Scenes/
│   ├─ MainMenu.unity          ← 你
│   └─ Level_01~03.unity       ← 队友
├─ UI/                          ← 你
│   ├─ Fonts/                   中文字体 .ttf + 生成的 Font Asset
│   ├─ Sprites/                 按钮、面板底图（九宫格）
│   └─ Prefabs/                 菜单里复用的部件
└─ Scripts/UI/                  MainMenu.cs / LevelSelectPanel.cs / SettingsPanel.cs
```

- 字体只用**一套**（比如思源黑体），全局统一，别混用
- 面板底图用 **九宫格（Sliced）**，不要拉伸普通图
- 所有 UI 预制体放 `Assets/UI/Prefabs/`，别扔在场景根

## 6. 你会踩的 6 个坑（按发生概率排序）

| # | 坑 | 表现 | 解决 |
|---|---|---|---|
| 1 | **场景没加进 Build Settings** | 编辑器里能跑，`LoadScene` 报 `couldn't be loaded` | 让队友把你场景加进去 |
| 2 | **TMP 中文变方块** | 全是 □□□ | 用 TTF 生成 Font Asset，`Atlas Population Mode = Dynamic` |
| 3 | **Canvas 没 EventSystem** | 按钮点不动 | 创建 Canvas 时会自动生成，删了就没救 |
| 4 | **跨场景拖引用** | 编辑器正常，打包后引用丢失 | 只能传场景名 / 用 `SaveSystem` |
| 5 | **新建了同名脚本** | `CS0101 命名空间已包含定义` | 别建第二个 `GameManager`，改现有的 |
| 6 | **Play 时改的场景没保存** | 关掉 Unity 全没了 | **改完立刻 `Ctrl+S`** |

## 7. 环境统一（第一次 clone 后必做）

1. Unity Hub 装 **2022.3.62f3c1**
2. 打开工程后：`Window > TextMeshPro > Import TMP Essential Resources`
3. `Edit > Project Settings > Player > Other Settings > Active Input Handling` = **Both**
4. `Edit > Project Settings > Editor` → `Asset Serialization = Force Text`（默认已是）
5. 中文字体：TTF 拖进 `Assets/UI/Fonts/` → `Window > TextMeshPro > Font Asset Creator` → **Atlas Population Mode 选 Dynamic** → 生成

## 10. 交付方式

1. 队友开分支 `feature/menu`
2. 只提交 `MainMenu.unity`、`Assets/UI/`、`Assets/Scripts/UI/` 下的菜单脚本
3. 合并前把**主菜单场景名**告诉队友（由他加进 Build Settings）
4. 合并后一起跑一遍第 8 节的验收清单
