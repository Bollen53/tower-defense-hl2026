## 常用免费素材站（都在 CC0 或 CC-BY 范围内）

| 站点 | 内容 | 备注 |
|---|---|---|
| https://kenney.nl/assets | 2D/3D 素材包、UI、音效 | **CC0，最省事，风格统一** |
| https://itch.io/game-assets/free | 独立素材 | 逐个看许可证 |
| https://opengameart.org | 老牌免费素材库 | 看每个条目的 License |
| https://freesound.org | 音效 | 注意区分 CC0 和 CC-BY |
| https://pixabay.com/music | 背景音乐 | 免费商用，但要看条款 |
| https://incompetech.com | Kevin MacLeod 的 BGM | CC-BY，需署名 |

> ⚠️ 两个坑：
> 1. **署名要求**：CC-BY 必须署名。把作者名字写进游戏「制作人员」界面，或写进本文件的表格里并在 README 引用。
> 2. **AI 生成的图**：如果用了 AI 绘图，也在这里写清楚「AI 生成 + 用的哪个模型」，别装作自己画的——评委问细节会露馅。
